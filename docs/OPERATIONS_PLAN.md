# 運用・拡充計画

## 目的

サイトを「ゲームの価格一覧」から、購入・売却前に相場を確認する人が継続的に訪れる情報サイトへ育てる。アクセス増加は、ページ数ではなく、独自データの継続更新・検索意図への適合・再訪導線で評価する。

## 担当分担

| 担当 | 作業 |
| --- | --- |
| Codex | CSVからの集計、ページ生成、グラフ・ランキング、内部リンク、計測イベント、検査、GitHub Pages公開 |
| 運営者 | 実際の価格確認、調査対象・情報源の承認、Search Consoleの確認、外部SNS・提携先への投稿 |
| 共同確認 | 価格条件、公開可否、検索対象化、誤記・リンク切れの確認 |

## 更新サイクル

### 毎週：アクセス確認

- Search Consoleで表示回数、クリック数、CTR、検索語句、ページを確認する。
- GA4では、ハード検索・並び替え・価格履歴選択・外部リンククリックを見る。
- 自分のブラウザは analytics=off を設定し、実利用と混同しない。
- 前週比ではなく、28日間と前の28日間を比較する。

### 毎月：価格データ更新

- data/price-history.csv にSwitch 30作品の新しい月を追加する。
- 中古販売価格と買取価格を別々に確認する。未確認の値は空欄にし、推測で埋めない。
- 重点10作品は data/price-observations.csv に同じ版・状態の店舗別価格を追加する。
- 本体価格は data/hardware-observations.csv に型番・状態・店舗・確認日を記録する。
- 更新後に npm test を実行し、data/price-trends.json とランキングを確認する。

### 公開時：反映確認

    npm test
    git status --short
    git add .
    git commit -m "Update monthly market data"
    git push origin main
    git push origin main:gh-pages

公開後は、トップページ、価格推移、重点作品1ページ、データJSONをライブURLで確認する。

## 拡充ロードマップ

### 段階1：データの継続性（実装済み・運用継続）

- 月次履歴と最新の複数店舗販売確認を同じグラフに表示する。
- 価格確認点数、確認日、情報源を表示する。
- 値上がり・値下がりランキングを最新データから生成する。
- 買取価格がない時点は販売価格だけを表示する。

### 段階2：検索対象の拡充

- 3回以上の価格確認がそろった作品を優先して強化する。
- PS4・PS5作品は、最低3店舗の確認価格・解説・出典がそろったものから noindex を外す。
- 本体は検索需要を見ながら、Switch Lite、PS5各型番、PS4 Pro、New 2DS LL、PSP、PS Vitaなどを追加する。
- レトロ本体は箱あり・本体のみ・欠品ありを分ける。

### 段階3：検索意図ページ

次のような1ページ1目的の特集を追加する。

- 「PS5 CFI-2000A01 中古相場」
- 「Switch 2とSwitch OLEDの中古価格比較」
- 「New 3DS LL 箱あり・本体のみの価格差」
- 「GBA SP 中古相場と確認ポイント」
- 「中古ゲームの値上がり・値下がりランキング」
- 「中古ゲームを買う前の付属品チェック」

各ページには、冒頭の結論、価格表、確認日、調査条件、出典、関連ページを必ず入れる。一般論だけの記事や、データのない大量ページは作らない。

### 段階4：再訪・外部流入

- 毎月「値上がり・値下がりTOP10」を公開する。
- 同じ集計をXなどで紹介し、サイトへ戻れるURLを付ける。
- 引用しやすいグラフと集計表を用意する。
- 価格アラートやRSSは、更新頻度が安定してから追加する。
- アフィリエイト導線は、価格情報と広告リンクを明確に分ける。

## 公開品質ゲート

以下を満たさないページは、検索対象にしない。

- タイトル・説明文・canonical・パンくずがある。
- 価格の確認日、条件、情報源URLがある。
- 販売価格と買取価格を混同していない。
- 複数店舗の件数と中央値の計算が確認できる。
- npm test が通る。
- noindex の未完成ページがサイトマップに入っていない。
- 構造化データがページ本文と一致している。

## 追跡するKPI

絶対目標は最初のSearch Console 28日データを基準に決める。

- Google検索の表示回数
- Google検索の非指名クリック数
- 検索CTR
- 検索流入のあるページ数
- 検索語句の種類
- 価格データの確認作品数・確認点数
- 価格推移ページから作品詳細への遷移
- 外部販売リンクのクリック数

90日間の目安は、表示回数3倍、検索クリック2倍、3時点以上の価格履歴30作品、検索意図ページ12本です。検索順位やアクセス数は保証値ではなく、データ更新後の推移で判断します。

## 判断が必要な事項

- PS4・PS5の価格確認に使う情報源と更新担当
- 本体追加の優先順位
- Search Consoleの週次確認担当
- SNS投稿を行う媒体と投稿頻度
- 買取価格を追加調査するか、販売価格中心にするか

## 現在の主な生成物

- data/price-history.csv：月次の販売価格・買取価格
- data/price-observations.csv：重点作品の店舗別販売価格
- data/price-trends.json：月次履歴と最新販売確認を統合した表示用データ
- data/market-summary.json：重点作品の中央値・確認範囲・参考判定
- data/hardware-summary.json：ゲーム機本体の集計データ
- sitemap.xml：検索対象ページの一覧

## 次回以降の履歴記録ルール

1. 変更前に git status --short で未関係の変更がないことを確認する。
2. 価格データを変更した場合は、確認日・条件・出典URLを同じ変更に含める。
3. npm test を実行し、結果をコミットメッセージまたは作業記録に残す。
4. 1つの目的ごとにコミットを分ける。
5. main と gh-pages に公開した後、ライブURLと変更ページを確認する。
6. この表に日付、コミット、変更内容、検証結果を1行追加する。

価格を推測して履歴を埋めること、確認していない買取価格を補間すること、未完成ページを検索対象にすることは禁止します。
